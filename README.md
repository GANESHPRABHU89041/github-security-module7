# GitHub Security - Module 7

## Project Overview
This repository demonstrates GitHub security
best practices and secure repository management.

## Security Checklist

- [x] Created a GitHub repository.
- [x] Created a .gitignore file.
- [x] Excluded .env files and log files.
- [x] Excluded unnecessary folders.
- [x] Created a safe .env.example file.
- [x] Used conventional commit messages.
- [ ] Enabled two-factor authentication (2FA).
- [ ] Reviewed GitHub Secret Scanning settings.
- [ ] Reviewed Push Protection settings.
- [ ] Reviewed collaborator permissions.
- [ ] Checked repository commit history.
- [ ] Verified that sensitive files are not tracked.

## Security Best Practices

1. Never upload passwords or API keys.
2. Keep environment variables private.
3. Use .gitignore to exclude sensitive files.
4. Enable two-factor authentication.
5. Enable secret scanning and push protection
   when available.
6. Provide minimum required repository permissions.
7. Review commit history regularly.
8. Rotate credentials if they are exposed.
